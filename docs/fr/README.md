# Parcours francais : sol2base (pont Solana vers Base)

Lecture pedagogique du depot base/sol2base ("Terminally Onchain") : une application Next.js a interface terminal qui ponte du SOL et des tokens SPL depuis un wallet Solana vers Base, avec la possibilite d attacher un appel de contrat Base a executer a la reception.

Sommaire :

Chapitre 1 Presentation de sol2base. Chapitre 2 Une configuration qui bascule integralement entre deux environnements. Chapitre 3 Construire les instructions du programme de pont a la main. Chapitre 4 Attacher un appel de contrat Base attache et interface en ligne de commande. Chapitre 5 Resoudre ENS et Basenames, et le guide de bout en bout pour ponter un nouveau token. Chapitre 6 Limites et perimetre de ce parcours.

Ce parcours est une lecture pedagogique du code source et de la documentation du depot, sans installation ni execution du projet.
